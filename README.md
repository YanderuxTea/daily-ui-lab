# UI Lab: Skill Refresher

---

### Доступен для заказов. [Мой профиль на Kwork](https://kwork.ru/user/teawithsuqar)

Мой личный полигон для оттачивания навыков фронтенд-разработки. Здесь я буду собирать изолированные UI-компоненты и
макеты каждый день.

**Цель:** Сохранять "чистоту кода" и скорость верстки на актуальном стеке, пока фокус смещен на другие задачи.

## Стек технологий

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)

---

## Посмотреть работы можно по этой [ссылке](https://daily-ui-lab.vercel.app/)

---

## Как запустить локально

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/YanderuxTea/daily-ui-lab.git
   ```
2. Перейти в папку

   ```bash
   cd daily-ui-lab
   ```

3. Установить зависимости

   ```bash
   pnpm install
   ```

4. Запустить
   ```bash
   pnpm dev
   ```

### 10. Notification Center Popover

- **Описание:** Попап-центр уведомлений с глобальным стейтом через `useState` + `useMemo`. Фильтрация `all / unread` реализована без дублирования данных — через `useMemo` от одного массива. ### 11. File Upload Dropzone

- **Описание:** Зона загрузки файлов с drag-and-drop, валидацией по размеру (10 MB) и анимированным прогрессом. Стейт вынесен в `DropzoneFullBlock` и передаётся вниз через `setFilesAction`. Контейнер дропзоны реагирует на статус (`success` / `error` / `none`) сменой border и background через Tailwind-классы; статус автоматически сбрасывается через `setTimeout` в `useRef` с очисткой через `clearTimeout` при каждом новом изменении. Scale-анимация при drag-over реализована через `motion.div` со spring (`stiffness: 300, damping: 22`). Список файлов рендерится через `AnimatePresence mode="popLayout"` — удаление карточки анимировано через `exit` (`opacity`, `x`, `height → 0`). Прогресс-бар в карточке реализован через `motion.div` с `initial width: 0 → animate width: 100%` и `onAnimationComplete` для переключения в `completed`-стейт — после чего fill меняет цвет с accent на success и появляется иконка чекмарка. Маппинг иконок и цветов по типу файла — через `Record<TypeFile, ...>` с прямой индексацией.
- **Тайминг реализации:** ~1.5 часа.
- **Путь:** `/file-upload-dropzone`

### 15. Tasks Board (Kanban)

- **Описание:** Интерактивная kanban-доска с поддержкой drag & drop между колонками. Перемещение задач реализовано через `framer-motion` (`drag`, `onDrag`, `onDragEnd`) с ручным определением зоны дропа через `document.elementsFromPoint`, что даёт полный контроль над логикой без сторонних DnD-библиотек. Во время перетаскивания используется локальное состояние (`isDragging`, `dragTask`) для управления визуалом (scale, opacity) и поведения. Обновление состояния доски происходит иммутабельно через `setTasksBoard`, включая перенос задачи между колонками и её удаление. Добавление задач реализовано через controlled `textarea` с генерацией `id` через `uuid` и форматированием даты через `Intl.DateTimeFormat`. Подсветка колонки при наведении (`onOverId`) синхронизирована с позицией курсора. Вся UI-система построена на Tailwind с кастомными токенами (`kb-*`), типографика комбинирует `Onest` для интерфейса и `Fira Code` для мета-информации.

### 17. Tech Tag Input

- **Описание:** Продвинутый компонент ввода тегов технологий с интеллектуальным поиском и клавиатурной навигацией. Основная логика фильтрации реализована через `useMemo`, который исключает уже выбранные элементы и подсвечивает совпадения в выпадающем списке с помощью регулярных выражений. Взаимодействие полностью оптимизировано для работы без мыши: поддержка `ArrowUp`/`ArrowDown` для выбора в списке, `Enter` для добавления и `Backspace` для быстрого удаления последнего тега. Управление ошибками автоматизировано через `useRef` и таймер для их плавного скрытия. Стилизация выполнена на Tailwind с использованием кастомных токенов (`ti-*`), шрифта `Golos Text` для основного интерфейса и `JetBrains Mono` для технических данных и горячих клавиш.

### 18. Smart Device Control (Climate)

- **Описание:** Интерактивный интерфейс управления климат-контролем с динамической визуализацией состояний. Ключевой особенностью является система адаптивного фонового свечения (glow effect), реализованная через абсолютное позиционирование с экстремальным `blur-[100px]`, которое меняет цвет в зависимости от выбранного режима (`cool`, `heat`, `auto`). Весь UI реагирует на состояние `isOn`: при выключении компоненты плавно теряют прозрачность, кнопки регулировки температуры блокируются через атрибут `disabled`, а центральный индикатор температуры смещается по вертикали. Анимации переключения режимов и изменения температуры выполнены с помощью `framer-motion`: используется `layoutId` для плавного перемещения индикатора выбора (segment control) и `AnimatePresence` с `initial={false}` для мгновенной смены цифр без графических артефактов. Стилизация базируется на Tailwind CSS с использованием стеклянных эффектов (`glassmorphism`), кастомных токенов `sdc-*`, шрифта `Unbounded` для акцентных цифр и `Plus Jakarta Sans` для основного интерфейса.
- **Тайминг реализации:** ~2 часа.
- **Путь:** `/smart-device-controller`

### 19. Quick Notes Widget

- **Описание:** Минималистичный и функциональный виджет для управления быстрыми заметками. Интерфейс построен на принципах **Glassmorphism**, используя `backdrop-blur-[18px]` и полупрозрачные границы для эффекта глубины. Ключевая особенность — интеллектуальная сортировка через `useMemo`, которая автоматически поднимает закрепленные (`pinned`) заметки вверх списка, учитывая время создания. Для интерактивности используется `framer-motion`: карточки имеют плавный вход (`initial/animate`), поддержку `layout` для "умного" перемещения при изменении порядка и `AnimatePresence` для эффектного удаления. Стилизация выполнена с использованием кастомных токенов Tailwind (`qn-*`), шрифта `Manrope` для интерфейса и `IBM Plex Mono` для таймстампов, подчеркивая "технический" характер приложения.
- **Тайминг реализации:** ~1.5 часа.

### 31. Tooltip

- **Описание:** Универсальный компонент‑подсказка, который появляется после настраиваемой задержки при наведении курсора.

  - **Варианты оформления:** 4 темв (default, success, dark, danger) - цвета контейнера и всплывающего окна берутся из `mapColorsTooltip`.
